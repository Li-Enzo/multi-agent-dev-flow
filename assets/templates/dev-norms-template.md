## 4. 代码协作规范

- 仓库结构：单仓 monorepo（client/ server/ migrations/ docs/ scripts/ CHANGELOG.md）。
- 分支：`main`（只接受合并，打 tag 发布）/ `dev` / `feature/<模块>-<简述>` / `hotfix/<简述>`。
- Commit：`type(scope): 简述`（feat/fix/docs/refactor/test/chore），正文注明关联文档章节。
- PR ≤ 400 行有效改动；必须过 lint + 单测 + ≥1 人评审；支付/退款/库存类 PR 附测试证据。
- 环境：dev/prod 分离；密钥只放环境变量与本地 `.env`（gitignore），禁止进聊天与文档。
- 数据库变更只走 `scripts/migrations/`，禁止手改生产库。
