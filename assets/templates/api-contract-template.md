## 1. 通用约定

### 1.1 请求

- 网关入口：`<基础URL>`，所有接口通过 `action` 字段或路径分发。
- 鉴权头：`Authorization: Bearer <token>`；未登录接口除外。
- 统一请求体：`{ "action": "<名>", "data": { ... } }`

### 1.2 统一响应

```json
{ "code": 0, "msg": "ok", "data": { } }
```

| code | 含义 |
| --- | --- |
| 0 | 成功 |
| 1001 | 参数错误 |
| 1002 | 未登录 / token 失效 |
| 1003 | 无权限 |
| 2001 | 业务校验失败（msg 带具体原因） |
| 2002 | 重复提交（幂等拦截） |
| 3001 | 第三方异常 |
| 5000 | 系统异常 |

### 1.3 通用字段约定

- 金额：整数「分」；时间：ISO 8601 UTC 字符串；分页：`cursor + limit`（游标 = `createdAt_id`）。
- 幂等：写接口支持 `idempotencyKey`（重试带同值，命中返回原结果，code=0）。
