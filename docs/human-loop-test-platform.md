# human-loop-test-platform — 系统设计构想

> 前言：vibe coding 让写代码变得极快，但"测试"成为最后一环的瓶颈——AI 自测烧 token 且测不出"人类会困惑"的问题（按钮没反应、文案歧义、某机型布局崩、流程绕晕新用户），传统 QA 流程服务不了没有 QA 流程的个人开发者，朋友/社区免费测又敷衍且碎片化。
>
> 本文档把讨论收敛为可执行的设计：定位、闭环、架构原则、双轨经济、验证路径。配套任务池见 `ROADMAP.md`「新产品」一节。

## 1. 定位：AI 编程工作流的"人类在环插件"

不是"一个测试平台"，而是嵌入 AI coding 工作流的一环：

```
AI 编程（写代码）
   ↓
平台发布 10-20 人真人快速众测（几小时内返回）
   ↓
AI 聚类去重、合成结构化报告（复现步骤/环境/期望行为/截图证据，可附修复建议）
   ↓
报告直接粘贴回 Cursor / Claude Code / v0 修复
   ↓
回归复测（同一批或新一批人）
```

报告格式按 AI coding agent 的输入习惯设计，开发者复制粘贴即可让 AI 去修——这个集成深度是现有自助测试平台都没做的，是实质壁垒。

## 2. 三个产品形态推论

1. **任务粒度极小**：按流程/功能点切片计价（"测一下注册流程""只测 iPhone SE 的支付页"），匹配小预算小应用。
2. **时效是核心竞争力**："24 小时内出结果"比"报告精美"重要十倍；SLA 与测试者在线调度（待命池）是运营难点。
3. **订阅制优于单次付费**：AI 应用更新频繁，"每月 N 次众测额度"平滑收入、锁定留存。

## 3. 架构原则

1. **MCP 是外衣，REST 是本体**。核心 API、鉴权、计费全走 REST；MCP server 只是薄适配层，Web 端/CI/未来其他 agent 框架都能复用。
2. **接口必须异步化**。MCP 是同步的，真人测试是几小时长任务：发布工具立即返回 `task_id`，提供 `get_status` / `get_report` 轮询工具（或 webhook + MCP resource）。
3. **AI 花真钱必须留人在环**。agent 可能循环调用或被提示词注入刷光余额：单次任务预算上限 + 日累计限额 + 超阈值强制人类确认（agent 生成任务草稿 → 人一键批准付款）。钱的环节永远有人确认，这是信任基础。
4. **任务发布要审核**。AI 自主发布的任务可能被用来发钓鱼 App/垃圾任务；发布前加自动 + 抽审机制，否则平台会变成滥用通道。
5. **MCP 工具描述（tool description）决定 agent 用不用得对**：太泛 agent 乱发布，太死限制自主编排。打磨程度可能比平台前端 UI 更重要。最小工具集：`publish_task` / `get_status` / `get_report`。

## 4. 双轨测试者经济

| 轨 | 人群 | 产出 | 报酬 | 关键机制 |
| --- | --- | --- | --- | --- |
| 积分轨 | 认证开发者 | 技术报告（看得懂崩溃日志、会给复现步骤） | 积分（以测抵测） | 有效期 6 个月制造消费紧迫感；月 earning cap 防刷分；30% 可提现锚定价；高价值任务优先派积分轨 |
| 现金轨 | 普通人 | 真实用户体验（"这里我很困惑"） | 现金 | 防作弊是生死线：录屏/操作轨迹证据、设备指纹、报告交叉验证（同一问题多人独立命中才算数）、信誉分 |

- **积分是平台负债**：开发者赚得快、消耗供给不足会积累未兑现"欠款"。有效期 + earning cap + 部分提现组合控制。
- **AI 合成报告层是真正的技术壁垒**：把技术报告与用户体验映射到同一问题框架聚类去重（20 个人的原始反馈 → 1 份干净报告），是低客单生意毛利做正的关键；自动化程度不够就退化成人力外包中介，模型不成立。
- **隐藏福利**：独立开发者自己是最理想的测试者供给，互测 + 积分抵扣缓解双边冷启动。

## 5. 商业验证优先（先于一切平台开发）

企划建立在两个未验证假设上，任一被证伪即 pivot：

- **假设一：独立开发者愿意为真人测试付费且复购**。"测试"对他们是可拖延、可替代的支出（朋友测/社区发帖/上线让用户骂都免费），转化率可能远低于预期。
- **假设二：AI 合成报告能把低客单生意的毛利做正**。

**两周人工撮合验证**（几乎零成本）：在 vibe coding 社区（v2ex、即刻、小红书、Cursor 中文群）找 5-10 个开发者，亲自当平台——组织 15 人测试、人工合成报告、收 50 元/单。只看两个数字：**复购率**与**报告被采纳修改的比例**。数字好 → 全力做 MCP-native 平台抢 1-2 年窗口；数字不好 → 零成本转向（AI coding 工具官方测试插件 / 开发者互测积分社区）。

## 6. 结构性风险

1. **三边冷启动死亡螺旋**：开发者/认证测试者/普通测试者三边互相依赖；普通人侧只能靠真金白银养着，烧钱期可能比预想长。
2. **巨头降维**：现有玩家加一层 MCP 接口是两周的事。防御 = 中文社区先发 + AI 报告合成的数据飞轮（越用越准，需时间积累）。
3. **信任单点致命**：未发布 App 被恶意传播/剽窃/平台被用来分发恶意软件，口碑在小开发者圈子传播极快，一次事件即崩塌。

## 7. 落地顺序

1. 人工撮合验证（两周，先看两个数字）
2. REST + Web 控制台 + 报告合成链路（核心 API/鉴权/计费/审核）
3. 最小 MCP 工具集上线宣传（"第一个能被 AI agent 自主调用的人类测试平台"叙事本身有传播价值）
4. 现金单轨跑通（开发者付钱、普通人接单、平台抽佣）
5. 积分轨后置上线（验证期是干扰项，规模小时是定时炸弹）
