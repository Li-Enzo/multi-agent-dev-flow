# 美术风格范式

> 核心思想：**风格是文档，不是感觉**。先写风格指导，再做 HTML 预览，用户裁决后按审查报告整改。没有文档约束的 AI 输出会滑向"默认审美"（渐变、阴影、圆角滥用）。

## 1. 风格指导文档（施工前必须存在）

用 `assets/templates/art-style-guide-template.md`，至少包含：

1. **风格定位**：一句话定调（如"冰蓝浆果·轻奢零渐变"），附 3-5 个关键词与反例描述。
2. **色彩与材质体系**：主色/辅色/功能色（成功/警告/错误）的精确色值；背景材质规则（纯色/纹理的边界）。
3. **构图与排版**：页边距、栅格、卡片间距、圆角上限、层级阴影规则（哪一级允许投影、投影参数）。
4. **字体规范**：字号阶梯（如 12/14/16/20/24）、字重使用场景、数字用等宽或表格数字。
5. **渐变红线**：默认禁止渐变；若某场景豁免（如会员卡卡面的金属光泽），**逐条写明豁免条款**（哪个元素、什么方向、起止色值），其余一律不许。
6. **美术禁忌清单**：显式列出禁止项。禁忌要具体到可执行（"禁止圆角超过 8px"优于"不要太过圆润"）。
7. **视觉验收清单**：交付时逐项勾选（色值一致/间距符合栅格/无违规渐变/字号阶梯正确…）。

## 2. HTML 预览先行

- 纯 HTML + CSS（可 Tailwind CDN）实现关键页面高保真预览，占位数据。
- 预览文件与风格指导放同一目录，命名带版本号（`会员中心-四等级材质卡面-V3.html`），改版不覆盖旧版，便于对照。
- 截图留档（首页布局、组件细节），作为后续实现的像素基准。

## 3. 审查与整改闭环

- 用户以**业主裁决**方式逐条过：通过项确认，违规项按严重度分级（P1 必须整改 / P2 应当整改），写入《美术风格审查整改报告》。
- 整改后逐条复核销项；报告归档，作为后续迭代的风格回归基线。
- 前端 UI 细节审核（字号/按钮/间距/位置）作为页面交付的固定工序，与风格审查报告互相独立、互为校验。

## 4. 品牌与文案规范（与视觉同等优先）

- 品牌名、品牌主张、各页面介绍文案、语气规范（如"描述性定位，非口号""避免医疗功效词"）。
- 所有界面文案引用此文档，禁止现场编造；违规文案与违规视觉同等级处理。

## 5. 素材管理

- AI 生成图/拍摄图统一命名（`主体_风格_版本.png`），白底图、场景图分目录。
- 入库素材记录来源与授权状态；小程序/网站素材另存压缩版本控制包体大小。
