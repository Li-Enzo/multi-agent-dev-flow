# 示例商城 · 测试与验收用例

> 测试 agent 不读实现代码，只按本文档执行。每轮迭代新增"用例集 N"并做全量回归。
>
> 本文件是 `assets/templates/test-cases-template.md` 的套用示例，对应契约见 `api-contract.example.md`。接口级冒烟用 `scripts/probe_api.py` 执行，示例命令见各用例备注。

## 用例集 A：核心链路

| 编号 | 场景 | 前置条件 | 步骤 | 预期结果 |
| --- | --- | --- | --- | --- |
| A01 | 新用户注册成功 | 短信服务可用，验证码已下发 | 调 `user.register`（phone + 正确 smsCode） | code=0；返回 userId/token/expiresAt；token 可调通需登录接口 |
| A02 | 注册参数非法 | — | 调 `user.register`，phone 传 "123" | code=1001，msg 提示手机号格式非法 |
| A03 | 重复手机号注册 | A01 已注册 | 换一个 idempotencyKey 再调 `user.register`，同手机号 | code=2001，msg 提示直接登录 |
| A04 | 注册幂等重放 | A01 请求原样重发 | 同 idempotencyKey 重复调 `user.register` | code=0；返回与首次相同 userId；不生成第二个账号 |
| A05 | 登录成功 | A01 已注册 | 调 `user.login`（正确手机号 + 密码） | code=0；返回新 token |
| A06 | 密码错误 | A01 已注册 | 调 `user.login`，密码错误 | code=2001，msg 提示密码错误 |
| A07 | 未注册手机号登录 | 手机号未注册 | 调 `user.login` | code=2001，msg 提示未注册（code 与 A06 统一，防账号枚举） |

> 备注：A01/A04 可用探针回归：`python scripts/probe_api.py -u <网关> -a user.register -d '{"phone":"13800138000","smsCode":"<动态值>","idempotencyKey":"<用例编号>"}' -e 0,1001,2001,2002`。验证码为动态值，用例运行时从种子数据读取，不硬编码。

## 用例集 B：登录态与鉴权

| 编号 | 场景 | 前置条件 | 步骤 | 预期结果 |
| --- | --- | --- | --- | --- |
| B01 | 无 token 访问需登录接口 | — | 不带 Authorization 调任意需登录接口 | code=1002 |
| B02 | 过期 token 访问 | token 已过期 | 带过期 token 调需登录接口 | code=1002 |
| B03 | 无权限点访问 | 已登录但无 `perm` | 调需权限点接口 | code=1003 |

## 验收集（用户亲自确认，约 30 分钟）

- [ ] 新用户从注册到登录的完整路径走通
- [ ] 重复提交注册（连点两次）只产生一个账号
- [ ] 退出登录后需登录页面全部拦截到登录页

## 性能与稳定性指标（上线门槛）

- 首屏加载：<2s（4G）
- 核心接口 P95：<300ms（user.register / user.login）
- 回归：全量用例 100% 绿

## 用例编写规则

1. **不用硬编码当前时间**：时间窗口用动态值（当前+2h；深夜顺延明天），否则中午后运行必挂。
2. 每个用例可独立重跑：种子数据自造、跑完自清理。
3. 新功能合入 = 新增用例集 + 全量回归通过，缺一不可。
